# Privacy Policy — Session Manager

*Last updated: June 2026*

Session Manager does not collect, store, transmit, or share any personal data.

All session data (tab URLs and titles) is stored exclusively on your local device 
using the browser's built-in `chrome.storage.local` API and never leaves your device.

**What we access:**
- Tab URLs and titles — only to save and restore sessions at your explicit request.

**What we do NOT do:**
- No data collection
- No analytics or tracking
- No third-party services
- No remote servers

For any questions: open an issue on this repository.# session-manager-privacy
